# 🎬 CineMind AI

> Seu assistente inteligente para descobrir filmes e séries.

O **CineMind AI** é uma aplicação web desenvolvida para ajudar
usuários a descobrir filmes e séries de forma mais inteligente
e personalizada.

A aplicação combina uma interface moderna desenvolvida em React
com um Backend em Node.js, integração com API do TMDB e recursos
de Inteligência Artificial para proporcionar uma experiência
interativa de descoberta de conteúdos.

## 🤖 CineMind AI

O principal diferencial do projeto é o assistente de Inteligência Artificial.

O usuário pode interagir com o CineMind AI através de perguntas e sugestões como:

- "Me recomende um filme"
- "Quero uma série"
- "Estou indeciso"
- "Quero assistir ficção científica"
- "Quero uma comédia"
- "Quero um romance"

A partir dessas interações, o assistente pode auxiliar o usuário na descoberta de novos conteúdos.
